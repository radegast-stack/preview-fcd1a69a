Análise e Desenvolvimento de Sistemas

Você se forma tecnólogo em Análise e Desenvolvimento de Sistemas em cinco semestres, preparado para analisar, projetar, documentar, testar, implementar e manter sistemas computacionais. No curso, você constrói sistemas reais para empresas reais com apoio do Núcleo de TI.

O percurso reúne o desenvolvimento de aplicações desktop, web e móveis nas principais linguagens de programação, além do projeto de bancos de dados para essas aplicações. Você estuda com recursos da Microsoft, AWS Academy, Red Hat Academy, Cisco Networking Academy e Autodesk Design Academy.
